# Fantasy Football Analyzer

A Python program for managing and analyzing fantasy football player statistics and performance.

## What It Does
- View and manage player lists
- Add new players to your roster
- Track weekly player statistics
- Calculate fantasy points based on performance
- Rank players by fantasy points
- Compare player statistics
- Analyze team performance
- Generate season summaries

## How to Run

1. Clone or download this repository.
2. Make sure Python 3 is installed.
3. Open a terminal in the project folder.
4. Run:

```bash
python fantasy_football_analyzer.py
